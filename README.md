## Exam Overview

The Dynatrace Implementation Professional Certification validates expert capabilities in enterprise deployment design, automated agent rollouts, data ingestion pipelines, and security configurations.

- **Exam Format**: Multiple-choice & technical scenario-based proctored exam
- **Target Audience**: Enterprise Architects, Implementation Engineers, Cloud Automation Engineers, Technical Consultants
- **Prerequisites**: Dynatrace Associate Certification

---

## Core Exam Domains & Knowledge Areas

### 1. Deployment Architectures & High Availability
- Designing high-availability (HA) topologies for hybrid multi-cloud environments.
- Network firewall rules, proxy requirements, and bandwidth optimization.

### 2. OneAgent Orchestration & Automation
- Automated OneAgent injection, silent installations, and scriptable rollouts.
- Container and Kubernetes Operator deployments, daemonsets, and sidecar injection.
- Updating, disabling, and troubleshooting OneAgent modules across OS platforms.

### 3. ActiveGate Topology & Management
- Environment ActiveGates vs. Cluster ActiveGates setup and configuration.
- Payload compression, proxying, private synthetic engine installation, and extension hosting.
- Routing strategies and ActiveGate high-availability load balancing.

### 4. OpenPipeline & Telemetry Ingestion
- Configuring OpenPipeline for routing, transforming, and enriching telemetry streams.
- OpenTelemetry (OTel) trace and metric ingestion setup.
- Prometheus metrics scraping, custom log enrichment, and REST API data ingestion.

### 5. Security & Network Configurations
- SSL/TLS certificate updates, security gateway routing, and token validation.
- Network security zones and endpoint protection policies.
